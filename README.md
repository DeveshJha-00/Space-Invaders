# Space Invaders

A classic Space Invaders clone written in Java! Survive through the 6 waves of enemies and get the highest score.

## How to Play

Download the latest release from the [Releases page](https://github.com/DeveshJha-00/Space-Invaders/releases) and run the executable `.jar` file:
```bash
java -jar SpaceInvaders-v1.0.0.jar
```
Or simply double-click the `.jar` file if you have Java installed.

## Controls

- **Up / Down / Left / Right Arrows**: Move your spaceship
- **Z**: Fire / Shoot bullets
- **Spacebar**: Restart the game when it's Game Over

## Game Features

### Waves & Enemies
- There are **6 Waves** in total.
- The enemies increase in difficulty and number as you progress through each wave. 
- You win by surviving and clearing all 6 waves!
- Different enemy types and ranks reward different amounts of points.

### Power-Ups
When you destroy enemies, they might drop power-ups to help you survive. Catch them with your ship!

- **Pink Square**: Extra Life (+1 Life). Very rare drop!
- **Small Yellow Square**: Power Up (+1 Power). Upgrades your firing power.
- **Large Yellow Square**: Mega Power Up (+2 Power). Upgrades your firing power by 2 levels.

### Score & Lives
- Your lives are displayed at the top-left of the screen.
- Getting hit by an enemy or their projectile reduces your lives. If you run out of lives, it's Game Over!
- Your score increases as you destroy enemies. Try to set a new high score!

Have fun defending the galaxy!
